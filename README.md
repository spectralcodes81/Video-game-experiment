# Stormbound

A browser-based wizard arena game. Progress is saved locally in the browser. Use a save code to transfer progress manually between devices without creating an account.

## Transfer progress

1. On the device with your progress, open **Save code** and select **Create code**.
2. Copy the code and transfer it privately to your other device.
3. On the other device, open **Save code**, paste the code, and select **Load code**. Loading replaces that device's current save.

Save codes contain only game progress and are not tied to an account. Anyone with a code can load or edit its progress, so avoid posting codes publicly.
